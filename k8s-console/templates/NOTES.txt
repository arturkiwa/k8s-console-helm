Klaster przygotowany dla zdalnej konsoli (RBAC + ServiceAccount {{ include "kc.sa" . }}).

1. Na klastrze konsoli utwórz Secret z tokenem i CA tego klastra:

   kubectl -n {{ .Release.Namespace }} get secret {{ include "kc.sa" . }}-token -o jsonpath='{.data.token}' | base64 -d > token
   kubectl -n {{ .Release.Namespace }} get secret {{ include "kc.sa" . }}-token -o jsonpath='{.data.ca\.crt}' | base64 -d > ca.crt
   kubectl --context <klaster-konsoli> -n <namespace-konsoli> create secret generic k8s-console-<nazwa> --from-file=token --from-file=ca.crt
   rm token ca.crt

2. Dopisz klaster w values konsoli (remoteClusters: name, server https://…, tokenSecret) i zrób helm upgrade.

Prefiks i grupy ({{ .Values.identity.prefix }}{{ .Values.groups.viewers }}, {{ .Values.identity.prefix }}{{ .Values.groups.operators }}) muszą być takie same jak w konsoli.
